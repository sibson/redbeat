Environment
-----------
 - mise is used to pin the Python version (see .mise.toml)
 - Install mise: https://mise.jdx.dev/getting-started.html
 - Then activate the environment:

    mise install
    mise activate

Testing
---------
 - uv (https://astral.sh/uv) manages the virtualenv and dependencies. Install
   it, then use make for setup and running tests:

    make setup
    make test

 - Or use uv manually:

    uv sync
    uv run python -m unittest discover tests

Linting
---------
    make lint

CI
---------
 - ci.yml: runs tests across the Python version matrix on push/PR
 - publish.yml: publishes to PyPI on tagged releases

Release
---------
 - release the next patch version to PyPI (runs tests before tagging):

    make release

 - for a minor/major release, bump the version first -- this is the one
   deliberate human decision in the process:

    make bump-version BUMP=minor   # or BUMP=major
    make release

 - create release in GitHub

    open https://github.com/sibson/redbeat/tags
